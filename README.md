# 🎮 Game Store System

A simple Java CLI-based application where users can browse games, add to cart, and purchase.

## 📌 Features:
- ✅ Browse a list of Nintendo games.
- ✅ Add games to a shopping cart.
- ✅ See the total price before purchasing.
- ✅ Purchase games successfully or fail if the cart is empty.

## 🛠 Tech Stack:
- **Java** (Object-Oriented Design)
- **JUnit 5** (Unit Testing)
- **Maven** (Build & Dependency Management)
- **GitHub Actions** (CI/CD for automated testing)
